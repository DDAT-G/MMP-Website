서비스 이용약관

최종 업데이트: 2026년 10월 8일

MMP는 대학 캡스톤 디자인 프로젝트로 개발 중인 비상업적 AI 기반 음악 플레이리스트 추천 및 관리 웹 애플리케이션입니다. 현재 공개 웹사이트는 프로젝트 소개를 위한 페이지이며, 실제 MMP 서비스는 개발 및 테스트 단계에 있습니다.

1. 서비스 개요

MMP는 사용자가 입력한 음악 관련 자연어 요청을 생성형 AI로 분석하여 음악을 추천하고, YouTube에서 관련 영상을 검색하여 플레이리스트 형태로 제공하는 서비스입니다.

사용자는 추천곡을 선택하고 플레이리스트를 생성, 조회, 수정 및 삭제할 수 있습니다.

2. 서비스 이용 조건

MMP는 현재 교육 및 프로젝트 시연 목적으로 개발되고 있으며, 별도의 이용 요금을 부과하지 않습니다.

현재 개발 버전에서는 자체 회원가입이나 로그인 기능을 제공하지 않습니다.

3. YouTube 서비스 이용

MMP는 YouTube Data API v3를 사용하여 음악 관련 영상 정보를 검색하고 제공합니다.

YouTube에서 제공하는 영상과 관련 정보의 권리는 해당 콘텐츠의 정당한 권리자에게 있습니다. MMP는 해당 영상의 소유권을 주장하지 않습니다.

MMP의 YouTube 관련 기능을 이용하는 사용자는 YouTube 서비스 약관의 적용을 받습니다.

4. AI 추천 결과

MMP의 음악 추천 결과는 생성형 AI를 기반으로 제공되며, 추천된 곡의 정확성이나 사용자의 취향과의 일치를 보장하지 않습니다.

검색 결과에 표시되는 영상은 YouTube에서 제공하는 정보를 기반으로 하며, 원본 영상의 공개 상태나 접근 가능 여부에 따라 재생이 제한될 수 있습니다.

5. 플레이리스트 데이터

현재 개발 버전에서는 플레이리스트 데이터를 개발 서버의 메모리에 임시 저장합니다. 서버가 재시작되면 저장된 데이터가 사라질 수 있습니다.

MMP는 현재 별도의 영구 저장 서비스나 사용자별 계정 기반 저장 기능을 제공하지 않습니다.

6. 향후 개발 예정 기능

MMP는 향후 Google OAuth 인증을 통해 사용자가 본인의 YouTube 계정에 플레이리스트를 내보내는 기능을 구현할 예정입니다.

해당 기능은 현재 제공되지 않으며, 구현 시 관련 권한, 이용 조건 및 개인정보처리방침을 검토하고 업데이트할 예정입니다.

7. 서비스 변경 및 제한

MMP는 개발 및 테스트 과정에서 기능이 추가, 변경 또는 중단될 수 있습니다. 외부 API의 장애, 사용량 제한 또는 기술적인 문제로 일부 기능이 일시적으로 제공되지 않을 수 있습니다.

8. 개인정보 보호

MMP의 정보 처리 방식은 별도의 개인정보처리방침에서 안내합니다.
