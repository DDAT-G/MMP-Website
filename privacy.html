MMP Privacy Policy

개인정보처리방침

최종 업데이트: 2026년 10월 8일

MMP는 대학 캡스톤 디자인 목적으로 개발 중인 비상업적 AI 기반 음악 플레이리스트 추천 서비스입니다. 본 문서는 MMP 프로젝트의 현재 개발 상태와 개인정보 및 외부 API 데이터 처리 방식을 설명합니다. 공개된 프로젝트 소개 웹사이트는 실제 음악 추천 애플리케이션과 별도로 운영됩니다.

1. 처리하는 정보

MMP의 음악 추천 기능은 사용자가 입력한 아티스트, 곡명, 장르, 분위기 및 자연어 요청을 처리합니다. 선택한 음악과 플레이리스트 정보도 기능 제공을 위해 처리됩니다.

현재 MMP는 자체 회원가입 및 로그인 기능을 제공하지 않습니다.

2. 정보 이용 목적

입력된 정보는 사용자의 음악 추천 요청 분석, YouTube 음악 영상 검색, 플레이리스트 생성 및 관리, 기능 테스트와 오류 확인을 위해 사용됩니다.

3. 외부 서비스 및 API

MMP는 OpenAI API를 통해 음악 추천 요청을 처리하며, YouTube Data API v3를 통해 관련 음악 영상을 검색합니다. 이 과정에서 요청 수행에 필요한 정보가 해당 서비스 제공자에게 전송될 수 있습니다.

외부 서비스의 데이터 처리에는 각 서비스의 개인정보처리방침 및 관련 정책이 적용됩니다.

4. 플레이리스트 정보의 저장

현재 개발 버전에서는 플레이리스트 정보를 개발 서버의 메모리에 임시로 저장합니다. 서버가 재시작되면 해당 정보가 사라질 수 있습니다. 개발 과정에서 기능 테스트 및 오류 확인을 위한 서버 로그가 생성될 수 있습니다.

5. Google 계정 연동

Google OAuth를 이용한 YouTube 플레이리스트 내보내기 기능은 현재 개발 예정이며, 아직 제공되지 않습니다.

향후 해당 기능이 구현될 경우 사용자 동의를 받은 후 필요한 권한만 요청하고, 실제 데이터 처리 방식에 맞춰 본 방침을 업데이트할 예정입니다.

6. 프로젝트 소개 웹사이트

현재 공개된 GitHub Pages 웹사이트는 MMP의 개발 목적과 기능을 안내하는 정적 페이지입니다. 웹사이트 호스팅 과정에서는 GitHub의 관련 정책이 적용될 수 있습니다.
