About MMP

기분을 설명하면, 음악으로 이어집니다.

MMP는 대학 캡스톤 디자인으로 제작한 비상업적 음악 추천 웹 애플리케이션입니다. 사용자의 자연어 요청과 사진·시간·날씨 등 여러 입력을 해석해 음악을 추천하고, YouTube 영상 검색과 재생목록 저장·편집·내보내기까지 하나의 흐름으로 연결하는 것을 목표로 개발했습니다.

01 / DISCOVERY

AI Music Recommendation

아티스트, 장르, 분위기와 청취 상황을 자연어로 입력하면 생성형 AI가 요청을 해석해 음악과 추천 이유를 제공합니다. 사진 분위기와 현재 시간·날씨를 활용하는 입력 방식도 구현했습니다.

기능 구현 · 배포 API 점검 중

02 / VIDEO SEARCH

YouTube Music Video Search

YouTube Data API v3로 추천된 곡명과 아티스트를 검색하여 관련 영상과 재생 시간을 표시합니다. 공식 채널 우선 검색, 관련성 평가 및 중복 검색을 줄이기 위한 캐시 로직을 사용합니다.

03 / ORGANIZE

Playlist Management

YouTube Integration

How YouTube API Is Used

음악 검색부터 개인 YouTube 재생목록 생성까지

01 · 음악 검색 및 표시

  1. 사용자가 자연어로 음악 추천을 요청합니다.
  2. AI가 아티스트와 곡명을 추천합니다.
  3. 서버가 YouTube Data API v3의 search.list를 호출합니다.
  4. 필요한 영상 정보와 재생 길이를 조회합니다.
  5. 검색된 영상을 MMP의 플레이리스트 화면에 표시합니다.

02 · YouTube Playlist Export

  1. 사용자가 내보낼 음악을 선택합니다.
  2. Google OAuth로 사용자 동의를 받아 YouTube 계정을 연결합니다.
  3. playlists.insert로 비공개 재생목록을 생성합니다.
  4. playlistItems.insert로 각 음악 영상을 목록에 추가합니다.
  5. 생성된 YouTube 재생목록의 링크를 사용자에게 제공합니다.

MMP는 개발·품질 검증을 위해 YouTube 검색과 내보내기 API를 사용합니다. API 할당량, Google 인증 권한 및 공개 배포 환경에 따라 일부 기능이 제한될 수 있습니다.

Project Status

Development Status

MMP는 웹 서비스가 공개 배포된 캡스톤 프로젝트입니다. 소개 페이지와 실제 웹 앱의 외부 접속은 가능하지만, AI 음악 추천은 API 사용 크레딧 문제로 점검 중이며 YouTube 내보내기의 공개 배포 인증 연동도 최종 확인이 필요합니다. 전시·교육을 위한 비상업적 프로젝트로 제공됩니다.
