CAPSTONE DESIGN PROJECT

MMP

AI Music Playlist Generator

생성형 AI 기반 음악 플레이리스트 추천 및 관리 플랫폼

사용자의 음악 취향과 상황을 자연어로 입력하여
맞춤형 플레이리스트를 생성하는 웹 애플리케이션

About MMP

MMP는 대학 캡스톤 디자인 프로젝트로 개발 중인 비상업적 음악 추천 웹 애플리케이션입니다. 사용자가 아티스트, 장르, 분위기 또는 청취 상황을 입력하면 생성형 AI가 요청을 해석하고 적절한 음악을 추천합니다.

Core Features

AI Music Recommendation

OpenAI API를 활용하여 자연어 입력을 분석하고 사용자의 요청에 적합한 실제 음악을 추천합니다.

Implemented · Improving

YouTube Music Video Search

YouTube Data API v3를 이용하여 AI가 추천한 아티스트와 곡명을 검색하고 관련 영상을 표시합니다. 검색 결과의 음악 관련성을 검증하는 기능을 개선 중입니다.

Implemented · Improving

Playlist Management

추천된 곡을 선택하고 플레이리스트를 생성하며, 저장, 조회, 이름 변경, 수정 및 삭제할 수 있습니다. 현재 저장 데이터는 개발 서버 메모리에서 관리됩니다.

Implemented

YouTube Playlist Export

Google OAuth 인증을 통해 사용자의 동의를 받은 후 선택한 플레이리스트를 본인의 YouTube 계정으로 내보내는 기능을 개발할 예정입니다.

Planned · Not Yet Available

How YouTube API Is Used

1. 사용자가 음악 추천 요청을 입력합니다.
2. OpenAI가 요청을 분석하고 아티스트 및 곡명을 추천합니다.
3. 서버에서 YouTube Data API v3의 search.list를 호출합니다.
4. 반환된 영상 정보를 플레이리스트 화면에 표시합니다.
5. 사용자는 선택한 음악을 YouTube 플레이어로 재생할 수 있습니다.

개발 및 품질 검증 과정에서 여러 곡에 대한 검색이 필요하며, 검색 정확도 테스트를 위해 추가 검색 할당량을 요청하고 있습니다.

Development Status

MMP는 현재 개발 및 테스트 단계에 있으며, 대학 캡스톤 디자인 전시를 목표로 준비 중입니다. 본 페이지는 프로젝트 소개를 위한 웹사이트이며, 실제 음악 추천 서비스와는 별도로 제공됩니다.
